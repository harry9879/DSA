# Operating System Basics

## What is an Operating System?

An Operating System (OS) is system software that acts as an interface between user and computer hardware.

## Goals of Operating System

- Convenience
- Efficiency
- Resource Management

## Types of Operating Systems

### Batch Operating System
- Jobs are executed in batches
- No direct user interaction

### Multiprogramming Operating System
- Multiple programs loaded in memory
- CPU utilization improves

### Time Sharing Operating System
- CPU time divided among users/processes
- Fast response time

### Real Time Operating System
- Strict timing constraints
- Used in embedded systems

## Functions of Operating System

- Process Management
- Memory Management
- File Management
- Device Management
- Security

## Advantages of Operating System

- Better hardware utilization
- Multitasking
- User-friendly interface

## Disadvantages

- Security threats
- Expensive
- Complex

## Important Short Notes

### Kernel
Core component of OS which directly interacts with hardware.

### Shell
Interface between user and operating system.
